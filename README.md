# AI IT Helpdesk Agent

## Project Overview
An AI-powered first-line IT Helpdesk Agent that diagnoses common technical issues and provides troubleshooting guidance using a knowledge base.

## Architecture
- Agent
- RAG (Retrieval-Augmented Generation)
- Tools

## Key Features
- AI-based issue diagnosis
- Knowledge base retrieval
- Grounded troubleshooting responses
- Tool-enabled workflow
- Human escalation support

## Working Process
User Query → Agent → RAG → Knowledge Base → Tools → Solution
